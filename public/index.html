import requests

url = "http://localhost:3000/send"
headers = {
    "Content-Type": "application/json",
    "x-api-key": "KUNCI_API_ANDA"
}
payload = {
    "to": "628123456789",
    "message": "Halo dari Python!"
}

response = requests.post(url, json=payload, headers=headers)

<?php
$ch = curl_init('http://localhost:3000/send');
$payload = json_encode([
    'to' => '628123456789',
    'message' => 'Halo dari PHP!'
]);

curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_POST, true);
curl_setopt($ch, CURLOPT_POSTFIELDS, $payload);

    'Content-Type: application/json',
    'x-api-key: KUNCI_API_ANDA'
]);

$response = curl_exec($ch);
curl_close($ch);

  "isCommand": true,
  "command": "tolong proses tiket #1024",
  "timestamp": 1725376500
}

• isGroup: Bernilai true jika pesan berasal dari Grup WhatsApp, atau false jika chat pribadi.

• isCommand: Bernilai true jika pesan diawali dengan kata nad,.

• command: Potongan isi teks setelah kata nad,.

Format Parameter "to":

• Nomor Personal: Masukkan nomor dengan kode negara (tanpa simbol + atau spasi). Contoh: 628123456789.
• Grup WhatsApp: Masukkan ID JID lengkap grup WhatsApp yang berakhiran @g.us. Contoh: 120363029988776655@g.us.

Prefix Perintah Bot ("nad,"):

Bot mendengarkan setiap pesan. Jika user mengirim pesan berawalan nad, (misal: nad, konfirmasi), bot akan membalas otomatis menandakan perintah diterima.

Keamanan & API Key:

Akses programmatik ke POST /send wajib menyertakan header x-api-key sesuai kunci yang aktif di server.
