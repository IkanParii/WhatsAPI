WhatsApp Terhubung & Siap Digunakan
Gateway online. Pesan masuk otomatis di-forward ke Webhook dan siap mengirim pesan via API.
Hubungkan WhatsApp
Pindai kode QR menggunakan akun WhatsApp ponsel Anda untuk mengaktifkan gateway.
Menghubungkan ke server WhatsApp...
1 Buka WhatsApp di ponsel Anda.
2 Buka Menu (tiga titik) atau Pengaturan → Perangkat Tertaut.
3 Ketuk Tautkan Perangkat lalu arahkan kamera ke kode QR di atas.
Kirim Pesan Teks
Kirim pesan langsung ke nomor kontak atau ke grup WhatsApp.
Daftar Grup WhatsApp
Salin ID JID grup untuk digunakan pada parameter tujuan to.

Hubungkan WhatsApp terlebih dahulu lalu klik Refresh.

API Key Programmatik
Kunci rahasia untuk header x-api-key saat mengakses endpoint API dari luar.

import requests

url = "http://localhost:3000/send"
headers = {
    "Content-Type": "application/json",
    "x-api-key": "API_KEY_ANDA"
}
payload = {
    "to": "628123456789",
    "message": "Halo dari Python"
}

r = requests.post(url, json=payload, headers=headers)
print(r.json())

    ]
